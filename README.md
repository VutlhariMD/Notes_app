# Notes Application

A secure note-taking mobile app built with **React Native**, **Expo Router** and **TypeScript**. Users register and log in, then create, organise, search and sort their notes across Work, Study and Personal categories. All data is stored on the device using AsyncStorage.







## Tech Stack
 React Native + Expo
 Expo Router
 TypeScript
 AsyncStorage
 expo-crypto
 React Context
 



## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (LTS version)
- The **Expo Go** app on your phone, or an Android/iOS emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start the app
npx expo start
```

Scan the QR code with Expo Go, or press `a` for Android emulator or `i` for iOS simulator.

## Usage

1. Open the app and tap **Register** to create an account.
2. Add a note with the category, optional title and text.
3. Browse notes by category using the tabs.
4. Use the search bar to find notes by word, and the sort option to order them by date.
5. Open the **Profile** tab to update your credentials or log out.
